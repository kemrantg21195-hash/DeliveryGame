# Файл: `My project\Assets\TutorialInfo\Scripts\Editor\ReadmeEditor.cs`

Ниже приведена документация по файлу `ReadmeEditor.cs`. Файл расположен в каталоге `Assets/TutorialInfo/Scripts/Editor/` и относится к стандартному набору ассетов Unity (Tutorial Info), который автоматически поставляется вместе с шаблонами проектов и предназначен для отображения приветственного файла‑инструкции «Readme» прямо в окне инспектора.

## Обзор файла

`ReadmeEditor.cs` — это редакторный (Editor‑only) скрипт Unity, расширяющий стандартную функциональность окна Inspector для кастомного ассета `Readme` (класс из одноимённого файла `Readme.cs`). Скрипт:

- регистрируется как пользовательский инспектор для типа `Readme` посредством атрибута `CustomEditor`;
- при загрузке редактора автоматически открывает приветственный ассет «Readme», если он ещё не показывался в текущей сессии;
- отображает красивую страницу‑заставку с логотипом, заголовком, текстом и кликабельными ссылками на разделы документации/обучающие материалы;
- добавляет команду в главное меню Unity для ручного вызова приветственной страницы.

Файл не содержит рантайм‑логики и работает исключительно внутри среды Unity Editor. На него распространяются общие правила редакторных скриптов: он должен лежать в папке с именем `Editor`, чтобы не попасть в финальную сборку, и может использовать API пространства имён `UnityEditor`.

**Ключевые зависимости (импорты):**

| Пространство имён | Назначение |
|-------------------|------------|
| `UnityEngine` | Базовые типы Unity (`Object`, `GUILayout`, `Texture2D`, `Mathf` и т.д.). |
| `UnityEditor` | API редактора: `Editor`, `CustomEditor`, `MenuItem`, `AssetDatabase`, `SessionState`, `EditorGUIUtility`, `Selection`. |
| `System.IO` | Файловые операции (используется для отрисовки иконок/текста и проверок путей). |
| `System.Reflection` | Рефлексия (применяется для доступа к внутренним/приватным членам редактора, например к полям раскладки). |

**Особенности реализации:**

- Скрипт статический по природе загрузки (`[InitializeOnLoad]` / статический конструктор), что позволяет выполнять код сразу после перезагрузки домена редактора.
- Состояние «уже показывали Readme» хранится в `SessionState`, то есть сбрасывается между сессиями редактора, но сохраняется при перекомпиляции в рамках одной сессии.
- Внешний вид вкладки строится вручную через `GUILayout`/`GUIStyle`, что даёт полный контроль над вёрсткой заголовка и секций.

## Описание классов и функций

### Класс `ReadmeEditor`

```
[CustomEditor(typeof(Readme))]
[InitializeOnLoad]
public class ReadmeEditor : Editor
```

Назначение: пользовательский инспектор для ассета `Readme`. Наследуется от `UnityEditor.Editor`.

**Атрибуты:**

- `[CustomEditor(typeof(Readme))]` — сообщает Unity, что данный класс рисует инспектор для объектов типа `Readme`.
- `[InitializeOnLoad]` — гарантирует вызов статического конструктора при загрузке/перекомпиляции скриптов редактора.

**Статические поля:**

- `kShowedReadmeSessionStateName` — строковый ключ (`"ReadmeEditor.showedReadme"`) для хранения флага «Readme уже показан» в `SessionState`.
- `kSpace` — константа (`float`, обычно `16f`), задающая стандартный вертикальный отступ между блоками вёрстки.
- (при наличии) статические ссылки на иконки/ресурсы, используемые для оформления заголовка.

**Поля экземпляра:**

- Стили (`GUIStyle`) для заголовка (`m_TitleStyle`), подзаголовка (`m_SubtitleStyle`), текста ссылок (`m_LinkStyle`), текста секций (`m_BodyStyle`) и т.п. Инициализируются лениво методом `Init()`.
- Возможно поле для отслеживания состояния раскрытия секций.

#### Статический конструктор `static ReadmeEditor()`

Сигнатура: `static ReadmeEditor()`

Что делает: подписывается на `EditorApplication.delayCall += SelectReadmeAutomatically;`. Благодаря этому метод автоматического показа Readme вызывается не мгновенно, а после того, как редактор закончит загрузку и стабилизирует состояние, что исключает ошибки обращения к объектам на этапе инициализации.

Параметры: нет.

#### `static void SelectReadmeAutomatically()`

Что делает:

1. Проверяет флаг в `SessionState` по ключу `kShowedReadmeSessionStateName`.
2. Если Readme в текущей сессии ещё не показывался — вызывает `SelectReadme()`.
3. Устанавливает флаг «показан» в `true`, чтобы окно не открывалось повторно.
4. Если ассет найден и у него ещё не загружена специальная раскладка (`loadedLayout == false`) — вызывает `LoadLayout()` и помечает раскладку как загруженную.

Параметры: нет.
Возвращаемое значение: нет.

#### `static void LoadLayout()`

Что делает: программно переключает редактор в заранее подготовленную раскладку (layout) интерфейса, наиболее удобную для просмотра обучающих материалов. Обычно реализуется через обращение к внутренним API редактора раскладок (с применением `System.Reflection`) либо через условную компиляцию для разных версий Unity (`#if UNITY_2019_1_OR_NEWER` и т.п.).

Параметры: нет.
Возвращаемое значение: нет.

#### `static Readme SelectReadme()`

```
static Readme SelectReadme()
```

Что делает:

1. С помощью `AssetDatabase.FindAssets("Readme t:Readme")` ищет в проекте ассеты с именем `Readme` и типом `Readme`.
2. Если найден ровно один ассет — загружает его через `AssetDatabase.LoadMainAssetAtPath`, выделяет в окне `Project` (`Selection.objects = ...`) и возвращает приведённым к типу `Readme`.
3. Если найдено не одно совпадение — пишет предупреждение в консоль (`Debug.Log("Couldn't find a readme")`) и возвращает `null`.

Параметры: нет.
Возвращаемое значение: `Readme` — найденный ассет или `null`.

Примечание: метод помечен либо вызывается из команды меню, поэтому может быть связан с `[MenuItem]`.

#### `[MenuItem("Tutorial/Show Tutorial Instructions")]` (команда меню)

Что делает: добавляет в главное меню Unity пункт «Tutorial → Show Tutorial Instructions», по нажатию которого вызывается `SelectReadme()`. Это позволяет повторно открыть приветственную страницу вручную, даже если она уже была показана в текущей сессии.

Параметры: нет (обработчик команды меню).

#### `protected override void OnHeaderGUI()`

Что делает: переопределяет отрисовку «шапки» инспектора. Вместо стандартного заголовка рисует оформленный блок с иконкой ассета, крупным заголовком (`readme.title`) в стиле `m_TitleStyle` и, при наличии, подзаголовком. Перед отрисовкой вызывает `Init()` для инициализации стилей. Ширина иконки вычисляется динамически от текущей ширины окна (`EditorGUIUtility.currentViewWidth`) с ограничением максимального размера, чтобы вёрстка корректно адаптировалась к размеру панели.

Параметры: нет.
Возвращаемое значение: нет.

#### `public override void OnInspectorGUI()`

Что делает: основная отрисовка тела инспектора для ассета `Readme`. Логика:

1. Вызывает `Init()` (ленивая инициализация стилей и ресурсов).
2. Для каждой секции ассета (`readme.sections`) вызывает вспомогательный метод `DrawSection(...)`.
3. Между секциями добавляет вертикальные отступы (`kSpace`).
4. Для каждой ссылки секции (`section.linkText`, `section.url`) выводит кликабельный текст через `GUILayout`/`EditorGUILayout` и открывает URL по нажатию (обычно через `Application.OpenURL`).
5. Завершает вёрстку, добавляя финальный отступ.

Параметры: нет.
Возвращаемое значение: нет.

#### `void Init()`

Что делает: ленивая инициализация стилей отображения. Если стили ещё не созданы, формирует объекты `GUIStyle` для заголовка, подзаголовка, тела текста и ссылок (шрифты, размеры, отступы, выравнивание, цвета). Повторный вызов не выполняет лишней работы. Обеспечивает единообразное оформление страницы Readme.

Параметры: нет.
Возвращаемое значение: нет.

#### `void DrawSection(Readme.Section section, ...)`

Что делает: отвечает за отрисовку одной секции приветственной страницы. Типовой алгоритм:

- выводит заголовок секции (`section.heading`) стилем заголовка;
- выводит основной текст (`section.text`) стилем тела с корректными переносами;
- если заданы `linkText`/`url`, отображает ссылку и обрабатывает клик, открывая внешний ресурс в браузере.

Параметры:

| Параметр | Тип | Описание |
|----------|-----|----------|
| `section` | `Readme.Section` | Данные секции: заголовок, текст, текст ссылки и URL. |
| (доп.) отступы/флаги форматирования | `float`/`bool` | Дополнительные параметры вёрстки (например, начальный и конечный отступ). |

Возвращаемое значение: нет.

#### Вспомогательные методы отрисовки (при наличии)

В зависимости от версии файла могут присутствовать приватные помощники, например:

- `void DrawLink(string linkText, string url)` — рисует кликабельную ссылку и по нажатию открывает `url` в системном браузере.
- `GUIStyle`‑геттеры — методы, возвращающие готовый стиль для конкретного типа контента.
- Утилиты проверки/загрузки иконок (работа с `Texture2D`, `AssetDatabase`).

Все они приватные, не имеют параметров настройки извне и служат исключительно поддержке основной отрисовки.

## Примеры использования

### Автоматический показ приветственной страницы

Специальных действий от разработчика не требуется: достаточно добавить в проект ассет `Readme` (создаётся через меню `Assets → Create → Readme`). При следующей загрузке редактора скрипт сам:

1. вызовет `SelectReadmeAutomatically()` из `delayCall`;
2. найдёт единственный ассет типа `Readme`;
3. откроет его в инспекторе и (при необходимости) переключит раскладку.

### Ручной вызов через меню

Если приветственная страница была закрыта, её можно открыть вновь:

```
Меню: Tutorial → Show Tutorial Instructions
```

Внутри это приводит к вызову `SelectReadme()`, который выделяет ассет и отображает в инспекторе вашу страницу Readme.

### Наполнение страницы контентом (косвенно влияет на отрисовку)

Хотя сам `ReadmeEditor` только отображает данные, содержимое формируется в ассете `Readme`. Пример структуры, на которую ориентируется редактор:

```
// Псевдокод структуры ассета Readme
title    = "Delivery Game Tutorial"
sections = [
    { heading = "Начало работы", text = "Откройте сцену ...", linkText = "Документация", url = "https://..." },
    { heading = "Управление",    text = "WASD — движение ...", linkText = "Видео",          url = "https://..." }
]
```

Каждая такая секция будет выведена методом `DrawSection`, а ссылки — открыты в браузере по клику.

### Переопределение поведения (расширение)

Чтобы изменить автоматическое поведение (например, не переключать раскладку или не показывать Readme при запуске), правят соответствующие методы:

- отключение автопоказа — закомментировать подписку `EditorApplication.delayCall += SelectReadmeAutomatically;` в статическом конструкторе либо всегда ставить флаг в `SessionState`;
- изменение оформления — редактировать `Init()` (шрифты, размеры, цвета) и `OnHeaderGUI()`;
- изменение набора секций отображения — править `OnInspectorGUI()`.

### Замечания по эксплуатации

- Файл обязан находиться в папке `Editor` (здесь — `Assets/TutorialInfo/Scripts/Editor/`), иначе сборка проекта завершится ошибкой из‑за ссылок на `UnityEditor`.
- Автопоказ завязан на `SessionState`, поэтому при каждом новом запуске редактора страница появится снова, а при обычной перекомпиляции в текущей сессии — нет.
- Скрипт безопасен для продакшена: он не влияет на игровой билд и работает только в редакторе.

При наличии расхождений в конкретной версии файла уточните имена приватных методов и полей по фактическому исходнику.
