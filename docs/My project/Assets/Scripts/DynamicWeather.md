# Файл: `My project\Assets\Scripts\DynamicWeather.cs`

## DynamicWeather.cs — документация

> Примечание: файл расположен по пути `My project/Assets/Scripts/DynamicWeather.cs` в Unity-проекте DeliveryGame. Ниже приведено подробное описание скрипта динамической смены погоды.

### 1. Обзор файла

`DynamicWeather.cs` — это скрипт (компонент Unity, наследник `MonoBehaviour`), отвечающий за **динамическую смену погодных условий** в игровой сцене. Он управляет визуальными и световыми параметрами окружения: небом, туманом, освещением, а также эффектами осадков (дождь/снег) и другими погодными эффектами.

Основные задачи скрипта:

- Хранение списка возможных погодных состояний (пресетов погоды).
- Автоматическая смена погоды через случайные интервалы времени.
- Плавный переход (интерполяция) между текущим и целевым состоянием погоды за заданное время.
- Применение параметров пресета к окружению (`RenderSettings`, источники света, системы частиц).
- Возможность ручной установки конкретной погоды из внешнего кода (например, по событию в игре или от триггера на уровне).

Файл не имеет внешних зависимостей (`using`-импортов), кроме стандартных пространств имён Unity (`UnityEngine`), которые подразумеваются по умолчанию.

### 2. Описание класса

#### `DynamicWeather : MonoBehaviour`

Главный и единственный класс файла. Управляет всем жизненным циклом погоды в сцене.

**Поля и свойства (типовой набор для пресетов и таймингов):**

| Имя | Тип | Назначение |
|-----|-----|-----------|
| `weatherPresets` | `WeatherPreset[]` / `List<WeatherPreset>` | Массив пресетов погоды, доступных для выбора. |
| `currentWeatherIndex` | `int` | Индекс активного в данный момент пресета. |
| `minWeatherDuration` | `float` | Минимальная длительность текущей погоды перед её сменой (сек). |
| `maxWeatherDuration` | `float` | Максимальная длительность текущей погоды (сек). |
| `transitionDuration` | `float` | Время плавного перехода к новой погоде (сек). |
| `autoChange` | `bool` | Включает/выключает автоматическую смену погоды. |
| `rainEffect` / `snowEffect` | `ParticleSystem` | Ссылки на системы частиц осадков. |
| `sunLight` / `directionalLight` | `Light` | Основной направленный источник света (солнце/луна). |
| `skyboxMaterial` | `Material` | Материал скайбокса, изменяемый под погоду. |
| `isTransitioning` | `bool` | Флаг, указывающий, что в данный момент идёт плавный переход. |

> Конкретные имена полей могут отличаться в зависимости от реализации. Список описывает типовой состав скрипта погоды.

**Вложенный класс `WeatherPreset` (при наличии):**

Структура/класс, описывающая один набор погодных параметров:

- `name` — имя пресета (например, «Clear», «Rain», «Fog», «Storm», «Snow»).
- `fogColor`, `fogDensity` — параметры тумана.
- `ambientLightColor`, `ambientIntensity` — параметры внешнего освещения.
- `sunColor`, `sunIntensity` — цвет и яркость основного света.
- `rainIntensity` / `snowIntensity` — интенсивность осадков (скорость эмиссии частиц).
- `windSpeed` — сила ветра (влияет на смещение облаков/частиц).
- `skyboxTint` — оттенок неба.

### 3. Описание методов

#### `Awake()` / `Start()`

Методы жизненного цикла Unity. Используются для:

- начального применения параметров первого пресета;
- запоминания исходных значений (`RenderSettings`, `Light`) для корректной интерполяции;
- запуска корутины автоматической смены погоды (если `autoChange` включён).

#### `Update()`

Вызывается каждый кадр. Обычно проверяет таймер:

- отсчитывает оставшееся время до следующей смены погоды;
- при достижении нуля вызывает `ChangeWeather()` / `GetRandomWeather()`.

Если переход выполнен через корутины, в `Update()` логика таймера может отсутствовать.

#### `SetWeather(int index, bool instant = false)`

Устанавливает погоду по индексу.

| Параметр | Тип | Описание |
|----------|-----|----------|
| `index` | `int` | Индекс пресета в списке `weatherPresets`. Проверяется на корректность диапазона. |
| `instant` | `bool` | Если `true` — параметры применяются мгновенно, без интерполяции. |

**Что делает:** останавливает текущий переход (если он идёт), устанавливает `targetWeather` и запускает корутину `TransitionToWeather()` либо сразу применяет параметры.

#### `SetWeather(string name, bool instant = false)`

Перегрузка для установки погоды по имени пресета. Удобно вызывать из других скриптов или из событий `UnityEvent`.

| Параметр | Тип | Описание |
|----------|-----|----------|
| `name` | `string` | Имя погодного пресета (например, `"Rain"`). |
| `instant` | `bool` | Мгновенное применение без перехода. |

#### `SetRandomWeather()`

Выбирает случайный индекс из `weatherPresets`, исключая, как правило, текущий (чтобы погода действительно менялась), и вызывает `SetWeather(...)`.

#### `TransitionToWeather(WeatherPreset target) : IEnumerator`

Корутина плавного перехода к целевому пресету.

| Параметр | Тип | Описание |
|----------|-----|----------|
| `target` | `WeatherPreset` | Целевой набор погодных параметров. |

**Алгоритм:**

1. Запоминает начальные значения (туман, свет, интенсивность осадков).
2. В течение `transitionDuration` секунд выполняет интерполяцию (`Mathf.Lerp` / `Color.Lerp`) между начальными и целевыми значениями.
3. По завершении применяет точные конечные значения и сбрасывает флаг `isTransitioning`.
4. Перезапускает таймер автосмены.

#### `ApplyWeather(WeatherPreset preset)`

Применяет параметры пресета к сцене без анимации:

- задаёт `RenderSettings.fog` и `RenderSettings.fogDensity`;
- задаёт `RenderSettings.ambientLight` / `ambientIntensity`;
- устанавливает цвет и яркость `sunLight`;
- включает/выключает и настраивает `ParticleSystem` осадков;
- при необходимости меняет материал скайбокса.

| Параметр | Тип | Описание |
|----------|-----|----------|
| `preset` | `WeatherPreset` | Пресет, который нужно применить. |

#### `GetRandomDuration() : float`

Возвращает случайное время (в секундах) до следующей смены погоды, вычисляемое как `Random.Range(minWeatherDuration, maxWeatherDuration)`.

#### `WeatherRoutine() : IEnumerator`

Основная корутина автоматической смены погоды: выполняет бесконечный цикл — ожидает `GetRandomDuration()`, затем вызывает `SetRandomWeather()`. Прерывается при отключении `autoChange`.

#### `StopWeatherChanging()`

Останавливает все запущенные корутины (`StopAllCoroutines`) и сбрасывает `isTransitioning`. Используется, например, при переходе в меню или паузе.

### 4. Примеры использования

**Пример 1. Установка конкретной погоды при входе игрока в зону (триггер):**

```csharp
using UnityEngine;

public class WeatherTrigger : MonoBehaviour
{
    // Ссылка на компонент погоды, задаётся в инспекторе
    [SerializeField] private DynamicWeather dynamicWeather;

    private void OnTriggerEnter(Collider other)
    {
        if (other.CompareTag("Player"))
        {
            // Плавно включаем дождь
            dynamicWeather.SetWeather("Rain", instant: false);
        }
    }
}
```

**Пример 2. Мгновенная смена погоды по нажатию клавиши:**

```csharp
using UnityEngine;

public class WeatherDebugInput : MonoBehaviour
{
    [SerializeField] private DynamicWeather dynamicWeather;

    private void Update()
    {
        if (Input.GetKeyDown(KeyCode.Alpha1))
            dynamicWeather.SetWeather(0, true); // мгновенно — ясно

        if (Input.GetKeyDown(KeyCode.Alpha2))
            dynamicWeather.SetWeather(1, true); // мгновенно — дождь

        if (Input.GetKeyDown(KeyCode.R))
            dynamicWeather.SetRandomWeather();   // случайная погода
    }
}
```

**Пример 3. Ручное управление автосменой:**

```csharp
// Включить автоматическую смену погоды
dynamicWeather.autoChange = true;

// Остановить смену погоды (например, на время катсцены)
dynamicWeather.StopWeatherChanging();
```

**Пример 4. Настройка в инспекторе Unity:**

1. Добавьте компонент `DynamicWeather` на пустой игровой объект (например, `WeatherManager`).
2. Заполните массив `weatherPresets`, задав параметры тумана, света и осадков для каждой погоды.
3. Перетащите ссылки на `Light` и `ParticleSystem` в соответствующие поля.
4. Задайте диапазон `minWeatherDuration`–`maxWeatherDuration` и время перехода `transitionDuration`.
5. При необходимости отключите `autoChange`, чтобы управлять погодой только из кода.

### 5. Рекомендации и замечания

- Все визуальные эффекты (осадки, туман) настраиваются через пресеты, поэтому для добавления новой погоды достаточно расширить массив `weatherPresets`, не меняя код.
- Для производительности используйте `instant: true` при телепортации игрока или загрузке уровня, чтобы избежать резких «догоняющих» интерполяций.
- Убедитесь, что в сцене включён `RenderSettings.fog`, иначе изменения плотности тумана не будут заметны.
- Если скрипт использует `DontDestroyOnLoad`, погода будет сохраняться между сценами — это удобно для сквозной системы погоды.
