В типовой реализации подобных скриптов ожидались бы методы вида:

## Примеры использования

Так как в файле отсутствуют класс и методы, напрямую подключить `CollisionSound` как компонент к GameObject и настроить его в инспекторе нельзя. Пример интеграции ниже носит **справочный характер** и показывает, как обычно реализуется и используется подобный скрипт в Unity.

### Ожидаемая (эталонная) реализация

```csharp
using UnityEngine;

public class CollisionSound : MonoBehaviour
{
    [SerializeField] private AudioSource audioSource;
    [SerializeField] private AudioClip collisionClip;
    [SerializeField] private float minImpactVelocity = 1.0f;

    private void OnCollisionEnter(Collision collision)
    {
        if (collision.relativeVelocity.magnitude >= minImpactVelocity && audioSource != null)
        {
            audioSource.PlayOneShot(collisionClip);
        }
    }
}
```

### Пример применения в сцене

1. Создать GameObject (например, коробку-посылку).
2. Добавить компоненты: `AudioSource`, `Collider`, `Rigidbody`.
3. Прикрепить скрипт `CollisionSound` к этому GameObject.
4. В инспекторе заполнить поля `audioSource` и `collisionClip`.
