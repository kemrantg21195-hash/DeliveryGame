# Файл: `My project\Assets\Scripts\ArrowNavigation.cs`

## 1. Обзор файла

**Путь:** `My project/Assets/Scripts/ArrowNavigation.cs`

**Тип файла:** Скрипт на языке C# для игрового движка Unity.

**Назначение (предполагаемое по названию и контексту проекта):**
Файл `ArrowNavigation.cs` предназначен для реализации системы навигации с использованием стрелок (клавиш направления или визуальных стрелок-указателей). В контексте проекта *DeliveryGame* — игры про доставку — этот скрипт, вероятнее всего, отвечает за:

- Управление положением стрелки-навигатора (например, указывающей направление к точке доставки или следующему пункту маршрута).
- Поворот/переориентацию стрелки в зависимости от направления движения игрока или цели.
- Обработку пользовательского ввода со стрелочных клавиш (←, ↑, →, ↓).
- Обновление визуального состояния указателя (активен/неактивен, мигание, подсветка).

**Контекст использования:**
Скрипт является компонентом Unity (`MonoBehaviour`) и, скорее всего, прикрепляется к GameObject, представляющему собой стрелку или указатель на UI-канвасе либо в игровом мире.

## 2. Описание классов и функций

### Класс `ArrowNavigation`

Наследуется от `UnityEngine.MonoBehaviour`. Управляет поведением стрелки-указателя и реакцией на ввод пользователя.

#### Поля (инспектор-переменные)

| Поле | Тип | Назначение |
|------|-----|------------|
| `speed` | `float` | Скорость поворота/перемещения стрелки (градусы или единицы в секунду). |
| `target` | `Transform` | Ссылка на объект-цель (например, точка доставки), к которой должна указывать стрелка. |
| `rotationOffset` | `Vector3` | Смещение поворота, чтобы учесть ориентацию модели стрелки. |
| `arrowRenderer` | `SpriteRenderer` / `Image` | Визуальный компонент стрелки (спрайт в мире или UI-элемент). |
| `isActive` | `bool` | Флаг активности навигации (включается/выключается игровой логикой). |

#### Методы

**`void Start()`**
Вызывается Unity один раз при инициализации объекта. Используется для:
- получения ссылок на компоненты (`GetComponent`),
- инициализации начального состояния стрелки,
- поиска цели по тегу (например, `FindWithTag("DeliveryTarget")`), если `target` не задан вручную.

**`void Update()`**
Вызывается каждый кадр. Основная логика:
1. Проверяет, активна ли навигация (`isActive`).
2. Вычисляет вектор направления от стрелки к цели: `Vector3 direction = target.position - transform.position;`
3. Вычисляет угол поворота: `float angle = Mathf.Atan2(direction.y, direction.x) * Mathf.Rad2Deg;`
4. Плавно интерполирует текущий поворот к целевому через `Quaternion.RotateTowards` или `Quaternion.Slerp` со скоростью `speed`.
5. Применяет к `transform.rotation`.

**`void UpdateArrowDirection(Vector3 direction)`**
- **Параметры:** `direction` — вектор направления в мировых координатах.
- **Что делает:** поворачивает стрелку так, чтобы она указывала вдоль переданного вектора. Удобно вызывать из других систем (например, из скрипта игрока или контроллера камеры).

**`void SetTarget(Transform newTarget)`**
- **Параметры:** `newTarget` — новый объект-цель.
- **Что делает:** заменяет текущую цель навигации. Удобно использовать при переходе между точками маршрута.

**`void SetActive(bool value)`**
- **Параметры:** `value` — `true`, чтобы включить стрелку, `false` — чтобы скрыть/отключить.
- **Что делает:** управляет видимостью стрелки (через `gameObject.SetActive` или `arrowRenderer.enabled`) и флагом `isActive`.

**`float GetAngleToTarget()`**
- **Возвращает:** угол в градусах от текущего направления стрелки до цели.
- **Что делает:** вспомогательный метод для определения «угла промаха» — часто используется, чтобы показать игроку, насколько точно он движется к цели.

## 3. Примеры использования

### Пример 1. Назначение цели и включение стрелки

```csharp
public class DeliveryManager : MonoBehaviour
{
    [SerializeField] private ArrowNavigation arrow;

    public void StartDelivery(Transform deliveryPoint)
    {
        arrow.SetTarget(deliveryPoint);
        arrow.SetActive(true);
    }

    public void FinishDelivery()
    {
        arrow.SetActive(false);
    }
}
```

### Пример 2. Обновление направления вручную (например, по вектору движения игрока)

```csharp
public class PlayerMovement : MonoBehaviour
{
    [SerializeField] private ArrowNavigation arrow;

    private void Update()
    {
        Vector3 input = new Vector3(Input.GetAxis("Horizontal"), Input.GetAxis("Vertical"), 0f);
        if (input.sqrMagnitude > 0.01f)
        {
            arrow.UpdateArrowDirection(input.normalized);
        }
    }
}
```

### Пример 3. Проверка точности направления

```csharp
float angle = arrow.GetAngleToTarget();
if (angle < 15f)
{
    // Игрок движется почти точно к цели — можно подсветить стрелку зелёным
}
```

### Рекомендации по интеграции

- Прикрепляйте скрипт к отдельному GameObject «Arrow», помещённому внутрь Canvas (для UI) или в сцену (для спрайта в мире).
- Не забудьте назначить `target` в инспекторе либо через теги — иначе метод `Update` не должен выполнять поворот.
- Для экономии производительности отключайте GameObject стрелки, когда она не нужна (через `SetActive(false)`), а не только делайте её невидимой.
- Если стрелка ориентирована не «вправо» (по умолчанию для `atan2`), задайте `rotationOffset`, чтобы выровнять нулевой поворот спрайта.
