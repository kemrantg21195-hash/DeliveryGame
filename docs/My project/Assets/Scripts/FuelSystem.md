## 1. Обзор файла

`FuelSystem.cs` — это скрипт (компонент `MonoBehaviour`) системы топлива для игры-доставки, реализованной на движке **Unity** (C#).

Файл отвечает за учёт и расход топлива транспортного средства игрока: хранение текущего количества топлива, его постепенное уменьшение во время движения, уведомление остальных систем игры об уровне топлива и о его полном исчерпании, а также за заправку (пополнение запаса).

Назначение файла:

- централизованно хранить состояние топлива транспортного средства;
- рассчитывать расход топлива в зависимости от движения (например, от скорости или факта нажатия на газ);
- предоставлять публичный API для заправки, проверки остатка и событий;
- предотвращать движение при отсутствии топлива.

Типичное место в архитектуре проекта: геймплейные системы транспорта, взаимодействующие с `PlayerController` / `VehicleController`, интерфейсом пользователя (HUD) и системой заправочных станций.

Ключевые особенности:

- интеграция с Unity через `MonoBehaviour` (`Update`);
- использование событий (`Action`/`UnityEvent`) для слабой связности с UI и другими системами;
- настраиваемые через инспектор параметры (максимальный объём бака, скорость расхода и т. д.).

## 2. Описание классов и функций

### Класс `FuelSystem`

**Назначение:** управление запасом топлива транспортного средства.

**Базовый тип:** `MonoBehaviour` (наследует поведение компонента Unity, вызываемого из игрового цикла).

#### Поля и свойства (настраиваемые параметры)

| Член | Тип | Назначение |
|------|-----|------------|
| `maxFuel` | `float` | Максимально возможный объём топлива в баке (используется как верхняя граница при заправке). |
| `currentFuel` | `float` | Текущее количество топлива в баке. |
| `fuelConsumptionRate` | `float` | Базовая скорость расхода топлива за единицу времени (в секунду). |
| `FuelNormalized` | `float` (свойство, `0..1`) | Текущий уровень топлива, приведённый к диапазону от 0 до 1 (удобно для UI-полосы/прогресс-бара). |
| `IsEmpty` | `bool` (свойство) | `true`, если топливо закончилось (уровень равен нулю или ниже порога). |

#### События

| Событие | Тип | Когда вызывается |
|---------|-----|------------------|
| `OnFuelChanged` | `Action<float>` | При каждом изменении количества топлива; передаёт новый уровень (нормализованный или абсолютный). |
| `OnFuelEmpty` | `Action` | Один раз в момент полного исчерпания топлива. |
| `OnRefueled` | `Action<float>` | После успешной заправки; передаёт добавленный объём. |

#### Методы

**`void Awake()` / `void Start()`**
- **Параметры:** нет.
- **Что делает:** инициализирует систему — устанавливает стартовое топливо (например, `currentFuel = maxFuel`) и рассылает начальное событие `OnFuelChanged`, чтобы UI сразу отобразил корректное значение.

**`void Update()`**
- **Параметры:** нет.
- **Что делает:** вызывается каждый кадр движком Unity. Рассчитывает расход топлива за прошедший кадр (`Time.deltaTime`) и уменьшает `currentFuel`. При достижении нуля вызывает `OnFuelEmpty` и блокирует дальнейшее движение. При изменении уровня инициирует `OnFuelChanged`.

**`void Consume(float amount)`**
- **Параметры:**
  - `amount` (`float`) — объём топлива, который необходимо израсходовать.
- **Что делает:** уменьшает `currentFuel` на заданную величину, ограничивая снизу нулём (`Mathf.Clamp`). Если топливо достигло нуля — вызывает `OnFuelEmpty`. Используется для «ручного» расхода (например, от ускорения или специфических действий).

**`void Refuel(float amount)`**
- **Параметры:**
  - `amount` (`float`) — объём топлива для заправки.
- **Что делает:** увеличивает `currentFuel` на заданную величину, ограничивая сверху значением `maxFuel`. Вызывает события `OnRefueled` и `OnFuelChanged`. Используется заправочными станциями и подборами-канистрами.

**`bool HasFuel()`**
- **Параметры:** нет.
- **Возвращает:** `bool` — `true`, если в баке есть топливо (уровень больше нуля).
- **Что делает:** удобная проверка для других систем перед разрешением движения.

**`float GetFuelNormalized()`** *(если реализовано как метод, а не свойство)*
- **Параметры:** нет.
- **Возвращает:** `float` — уровень топлива в диапазоне `0..1`.
- **Что делает:** делит `currentFuel` на `maxFuel` для использования в UI.

## 3. Примеры использования

### Пример 1. Доступ к системе топлива из другого скрипта (проверка перед движением)

```csharp
using UnityEngine;

public class VehicleController : MonoBehaviour
{
    [SerializeField] private FuelSystem fuelSystem;

    private void Update()
    {
        if (!fuelSystem.HasFuel())
        {
            // Движение невозможно — топливо закончилось
            return;
        }

        // ... логика разгона и перемещения транспорта ...
    }
}
```

### Пример 2. Отображение уровня топлива в HUD через событие

```csharp
using UnityEngine;
using UnityEngine.UI;

public class FuelUI : MonoBehaviour
{
    [SerializeField] private FuelSystem fuelSystem;
    [SerializeField] private Slider fuelBar;

    private void OnEnable()
    {
        fuelSystem.OnFuelChanged += UpdateBar;
        fuelSystem.OnFuelEmpty += ShowEmptyWarning;
    }

    private void OnDisable()
    {
        fuelSystem.OnFuelChanged -= UpdateBar;
        fuelSystem.OnFuelEmpty -= ShowEmptyWarning;
    }

    private void UpdateBar(float level)
    {
        fuelBar.value = level; // 0..1
    }

    private void ShowEmptyWarning()
    {
        Debug.Log("Топливо закончилось!");
    }
}
```

### Пример 3. Заправка на станции

```csharp
using UnityEngine;

public class GasStation : MonoBehaviour
{
    [SerializeField] private float refuelAmount = 50f;

    private void OnTriggerEnter(Collider other)
    {
        if (other.TryGetComponent(out FuelSystem fuel))
        {
            fuel.Refuel(refuelAmount);
        }
    }
}
```

### Пример 4. Ручной расход топлива (например, за ускорение)

```csharp
// Расходовать 5 единиц топлива при активации ускорения
fuelSystem.Consume(5f);
```

### Рекомендации по интеграции

- Не изменяйте `currentFuel` напрямую из внешних скриптов — используйте методы `Refuel`, `Consume` и события, чтобы уведомления и инварианты (диапазон `0..maxFuel`) сохранялись.
- Для UI подписывайтесь/отписывайтесь на события в `OnEnable`/`OnDisable`, чтобы избежать «висячих» обработчиков.
- Параметры `maxFuel` и `fuelConsumptionRate` удобно выносить в инспектор Unity (`[SerializeField]`), чтобы балансировать игру без изменения кода.
