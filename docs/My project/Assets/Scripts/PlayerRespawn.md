## 3. Примеры использования

Поскольку реализация отсутствует, примеров вызова функций из данного файла привести невозможно — вызывать нечего.

### 3.1. Рекомендуемый шаблон-заготовка

Если файл создавался под механику респауна, типовой скелет мог бы выглядеть так (это **предложение**, а не содержимое текущего файла):

```csharp
using UnityEngine;

public class PlayerRespawn : MonoBehaviour
{
    [SerializeField] private Transform respawnPoint; // точка возрождения
    [SerializeField] private Transform player;       // ссылка на игрока

    /// <summary>Возвращает игрока в точку возрождения.</summary>
    public void Respawn()
    {
        if (player == null || respawnPoint == null) return;
        player.position = respawnPoint.position;
        player.rotation = respawnPoint.rotation;
    }
}
```

### 3.2. Как это могло бы использоваться в сцене

1. Создать пустой GameObject (например, `RespawnPoint`) и расположить его в стартовой точке уровня.
2. Добавить компонент `PlayerRespawn` на объект-менеджер уровня.
3. В инспекторе перетащить ссылки: `respawnPoint` → `RespawnPoint`, `player` → объект игрока.
4. Вызывать `Respawn()` из кода обработки смерти (например, из скрипта игрока или триггера зоны падения):

```csharp
// Пример вызова из другого скрипта
private PlayerRespawn respawn;

private void Awake()
{
    respawn = FindFirstObjectByType<PlayerRespawn>();
}

private void OnDeath()
{
    respawn.Respawn();
}
```
